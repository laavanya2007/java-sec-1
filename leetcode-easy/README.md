# 50 Easy LeetCode Problems (Java, beginner-level)

One file per problem. Each file has the solution plus a `main` that runs the LeetCode examples and prints PASS/FAIL.

Run any one:
```
cd leetcode-easy
javac P01_FizzBuzz.java
java P01_FizzBuzz
```

| Section | Files |
|---|---|
| 1. Numbers, Conditions & Loops | P01 – P10 |
| 2. Strings | P11 – P20 |
| 3. Basic Arrays | P21 – P35 |
| 4. Problem Solving with Loops & Arrays | P36 – P45 |
| 5. 2D Arrays | P46 – P50 |

Notes: P08 is listed twice in the original sheet, so it shows a second (String-based) approach. P10 uses an int array instead of a linked list to stay beginner-friendly.
